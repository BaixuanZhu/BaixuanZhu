# BaixuanZhu

> **Building deterministic CLI tools for Windows developers & AI agents.**

为 Windows 开发者与 AI Agent 打造确定性的命令行工具——行为可预期、安装零门槛、更新全自动。

## 旗舰产品

| 项目 | 它解决什么 | 栈 |
|------|-----------|----|
| **[JVM](https://github.com/BaixuanZhu/JVM)** | Windows 上的 JDK 版本管理器：多发行版一键安装、junction 秒级切换、当前终端即时生效。[官网](https://baixuanzhu.github.io/JVM/) | Go |
| **[skills](https://github.com/BaixuanZhu/skills)** | 中文 Java/Spring 生态的 Agent Skills 套件：编码契约、测试策略、Sa-Token / MyBatis-Plus、敏捷流程 | Claude Code 插件 · npx |
| **[danbooru-tag-mcp](https://github.com/BaixuanZhu/danbooru-tag-mcp)** | AI 出图前校验真实 Danbooru 标签：名称、别名、共现统计，8 个 MCP 工具走 stdio | Go |
| **[claude-code-hooks](https://github.com/BaixuanZhu/claude-code-hooks)** | 给 Claude Code 补上原生 GUI：权限对话框、选项提问、桌面通知，零依赖 | Python |
